One Day, Everywhere — a magazine-style front page for Sunday 22 November 2026. 35 stories, all verified against Reuters, AP, BBC, ESPN, JMA, ATP, BWF, WAFA, UKMTO, CENTCOM, ABC, CBS, AAP, The Hindu, Punch and Pen Agency, each with its source noted. Pure Python standard library renderer (no Pillow): a 5x7 bitmap font, a small canvas, and a PNG encoder, drawing a navy masthead, a globe-and-thermometer hero for the COP31 collapse, two second-row features, a ten-story grid, a 22-story brief list, and a stats strip.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024) to `MAKEFUN_OUTPUT_DIR` when set, otherwise to `output/`.
